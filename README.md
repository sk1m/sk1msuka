# SK1MSUKA — сайт бренда одежды

Простой статический интернет-магазин: HTML + CSS + JS, без сборки и зависимостей.

## Запуск
Открой `index.html` в браузере. Или задеплой папку на GitHub Pages / Netlify / Vercel.

## Что есть
- Каталог с фильтром по категориям и сортировкой
- Карточка товара: выбор размера и количества
- Корзина (сохраняется в браузере), промокоды `SK1M10` (−10%) и `WELCOME` (−15%)
- Бесплатная доставка от 5 000 ₽
- Оформление заказа с проверкой полей
- Подписка на рассылку, мобильное меню, адаптивная вёрстка

## Как поменять
- Товары, цены, фото и промокоды — в начале `app.js` (`PRODUCTS`, `PROMOS`)
- Цвета — переменные в начале `styles.css`
- Тексты — в `index.html`

Фото взяты с [Unsplash](https://unsplash.com/license) (бесплатно для коммерческого использования).
Если фото не загрузилось, вместо него показывается заглушка с названием товара.

Заказы никуда не отправляются — это демо. Для реальных продаж нужно подключить оплату и бэкенд.
