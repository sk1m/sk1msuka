# VapeShop — Telegram-бот магазина

Каталог «Категория → Бренд → Товар» с фото, наличием, цветами и ценой; кнопка «Купить» отправляет заявку админам;
скрытая админ-панель по списку ID и паролю. Python + aiogram + SQLite, без платных сервисов.

Подробная инструкция — **[ИНСТРУКЦИЯ.txt](ИНСТРУКЦИЯ.txt)**.

Быстрый старт: `./start.sh` (Mac/Linux) или `start.bat` (Windows) — мастер спросит токен, ID админов и пароль.
Фоновый режим на Mac: `./mac_autostart.sh`. Сервер Ubuntu: `bash server_install.sh`.

| Файл | Что это |
|---|---|
| `bot.py` | бот: каталог, покупка, админ-панель |
| `db.py` | база SQLite: категории, бренды, товары, заявки |
| `assets/banner.png` | картинка приветствия |
| `setup_env.py` | мастер настройки `.env` |
