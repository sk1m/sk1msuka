# Знакомства — поиск по критериям

Приложение в стиле «Дайвинчика»: листаешь анкеты и жмёшь «да» или «нет». HTML + CSS + JS, без сборки и зависимостей.

## Запуск
Открой `dating/index.html` в браузере.

## Что есть
- Переключатель **Девушки / Парни**
- Фильтры: возраст, рост, вес, цвет волос, цвет глаз, телосложение, город, цель знакомства, курение, знак зодиака.
  Сразу видно, сколько анкет подходит
- Лента: ❤️ — да, 👎 — нет, 💌 — лайк с сообщением. Можно свайпать или жать ← / → на клавиатуре
- Взаимные симпатии (пары) и список тех, кого ты лайкнул(а)
- Своя анкета с превью
- Всё сохраняется в браузере (localStorage)

## Важно
Это демо: 300 анкет (150 девушек и 150 парней) сгенерированы случайно, люди вымышленные.
Фото — стоковые портреты моделей с [Unsplash](https://unsplash.com/license), 12 женских и 12 мужских, они повторяются по кругу.
Параметры анкеты (волосы, глаза, рост) с фото не совпадают. Если фото не загрузилось (нет интернета),
показывается нарисованный аватар по параметрам анкеты. Взаимность имитируется случайно (шанс 40%, с сообщением 60%).
Чтобы знакомились реальные люди, нужен бэкенд: регистрация, база анкет, фото, чат и модерация.

## Как поменять
Начало `dating/app.js`: варианты фильтров (`OPTIONS`), имена, тексты «о себе», количество анкет и шанс взаимности (`MATCH_CHANCE`).
