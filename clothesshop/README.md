# ClothesShop — Telegram-бот магазина одежды

Каталог «Категория → Подкатегория → Вещь» с фото, ценой, цветом, описанием и **размерами в наличии**.
Покупатель жмёт «🛒 Купить — M», а владельцу приходит заявка с ником, вещью и размером.
Скрытая админ-панель (только по списку ID и паролю): добавлять вещи, менять цены, размеры, фото, наличие, делать рассылку.
Python + aiogram + SQLite, без платных сервисов.

Подробная инструкция — **[ИНСТРУКЦИЯ.txt](ИНСТРУКЦИЯ.txt)**.

Быстрый старт: `./start.sh` (Mac/Linux) или `start.bat` (Windows) — мастер спросит токен, ID админов и пароль.
Фоновый режим на Mac: `./mac_autostart.sh`. Сервер Ubuntu: `bash server_install.sh`.

| Файл | Что это |
|---|---|
| `bot.py` | бот: каталог, покупка по размерам, админ-панель |
| `db.py` | база SQLite: категории, подкатегории, вещи, заявки |
| `assets/banner.png` | картинка приветствия (замени своей с тем же именем) |
| `setup_env.py` | мастер настройки `.env` |
