# PhoneBot — AI-сравнение телефонов в Telegram

Бот сравнивает смартфоны по характеристикам с помощью Claude (AI от Anthropic).
Работает по подписке: без кода активации доступ закрыт.

## Как это работает
1. Человек запускает бота и видит «⛔ Подписка не активна» и твой контакт для покупки.
2. Он нажимает «💳 Купить код». Тебе приходит уведомление, вы договариваетесь в личке.
3. Ты заходишь в «🛠 Админ-панель», жмёшь «➕ Создать код», выбираешь срок (7 / 30 / 90 дней или навсегда) и отправляешь код клиенту.
4. Клиент жмёт «🔑 Ввести код», вводит его и видит «✅ Подписка активна до …». Бот заработал.

Коды одноразовые. Если ввести новый код при действующей подписке, срок продлевается.

## Кнопки и команды
Внизу: «📱 Сравнить телефоны», «🔑 Ввести код», «👤 Моя подписка», «💳 Купить код», «🛠 Админ-панель».
В меню команд: /start, /compare, /code, /status, /buy, /new (новый диалог), /admin.

## Админ-панель
Вход: кнопка «🛠 Админ-панель» или /admin, затем пароль из `ADMIN_PASSWORD` (по умолчанию `1234`).
Для админа бот бесплатный и без лимитов. В панели:
- ➕ Создать код (7 / 30 / 90 дней, навсегда)
- 📋 Коды: свободные и кем использованы
- 👥 Подписчики с датами окончания
- 🚫 Отключить подписку по Telegram ID
- 📊 Статистика: пользователи, подписки, запросы

После 5 неверных паролей вход блокируется на 15 минут. Сообщение с паролем бот сразу удаляет из чата.

> ⚠️ Пароль `1234` подбирается за минуты. Перед запуском поставь свой длинный пароль в `ADMIN_PASSWORD`
> и впиши свой Telegram ID в `ADMIN_IDS`: тогда в админку не пустит никого, кроме тебя, даже с паролем.

## Запуск
1. Создай бота у [@BotFather](https://t.me/BotFather) и возьми токен.
2. Получи ключ Claude API: https://platform.claude.com/settings/keys (запросы платные, оплата по токенам).
3. Узнай свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
4. Установи и запусти (нужен Python 3.10+):
   ```bash
   cd phonebot
   python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   cp .env.example .env    # и заполни .env
   python bot.py
   ```

Бот работает, пока запущен скрипт. Чтобы он работал для всех круглосуточно, запусти его на сервере
(любой VPS, Railway, Render, Fly.io) той же командой `python bot.py`.

## Настройки (`.env`)
| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `ANTHROPIC_API_KEY` | ключ Claude API |
| `ADMIN_PASSWORD` | пароль админки |
| `ADMIN_IDS` | твой Telegram ID (через запятую, если несколько) |
| `OWNER_CONTACT` | ник, куда писать за кодом (по умолчанию @skimsuka) |
| `DAILY_LIMIT` | AI-запросов в сутки на подписчика (по умолчанию 50) |
| `DB_PATH` | файл базы SQLite |

## AI
Модель `claude-opus-5-5`, с поиском в интернете (до 3 поисков на ответ), чтобы брать свежие характеристики новых моделей.
Бот помнит последние 6 сообщений диалога, поэтому можно задавать уточнения («а по камере?»).
Модель и инструкции меняются в `ai.py`.
