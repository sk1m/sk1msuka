══════════════════════════════════════════════════════════════
   PHONEBOT на Mac — установка и настройка через Терминал
══════════════════════════════════════════════════════════════

Перед началом приготовь (см. ИНСТРУКЦИЯ.txt, части 1 и 2):
  • токен бота от @BotFather  (вида 7123456789:AAH...)
  • свой Telegram ID от @userinfobot  (число вида 123456789)

Команды ниже копируй целиком и вставляй в Терминал (Cmd+V),
затем нажимай Enter. Строки, которые начинаются с #, — пояснения,
их вводить не нужно.


──────────────────────────────────────────────────────────────
 ШАГ 1. Открой Терминал
──────────────────────────────────────────────────────────────

  Нажми Cmd + Пробел, напиши «Терминал» (или Terminal), нажми Enter.


──────────────────────────────────────────────────────────────
 ШАГ 2. Проверь Python (нужен 3.10 или новее)
──────────────────────────────────────────────────────────────

  python3 --version

  • Если ответ Python 3.10, 3.11, 3.12, 3.13 или новее — переходи к Шагу 3.
  • Если Python 3.9 или выскочило окно «установить инструменты
    разработчика» — встроенный Python устарел. Установи свежий:

    Способ А (проще): скачай с https://www.python.org/downloads/
      жёлтую кнопку «Download Python 3.x» и установи как программу.
      Потом закрой Терминал (Cmd+Q) и открой снова.

    Способ Б (если есть Homebrew):
      brew install python

  Проверь ещё раз:
    python3 --version


──────────────────────────────────────────────────────────────
 ШАГ 3. Положи бота в домашнюю папку
──────────────────────────────────────────────────────────────

  Safari обычно сам распаковывает архив в «Загрузки».
  Выполни команды (они работают в обоих случаях — и с архивом, и без):

    cd ~/Downloads
    [ -f phonebot.zip ] && [ ! -d phonebot ] && unzip -q phonebot.zip
    mv phonebot ~/phonebot
    cd ~/phonebot

  Сними с файлов «карантин» macOS и разреши запуск скриптов:

    xattr -dr com.apple.quarantine ~/phonebot
    chmod +x start.sh mac_autostart.sh server_install.sh

  Проверь, что файлы на месте:

    ls

  Должны быть: bot.py  db.py  products.py  start.sh  mac_autostart.sh ...


──────────────────────────────────────────────────────────────
 ШАГ 4. Первый запуск и настройка
──────────────────────────────────────────────────────────────

    ./start.sh

  Скрипт сам установит всё нужное (1–2 минуты), потом спросит:

    1) Токен бота          → вставь токен (Cmd+V), Enter
    2) Пароль админ-панели → свой пароль или просто Enter (сгенерирует сам).
                             ЗАПИШИ ПАРОЛЬ, он покажется в конце.
    3) Твой Telegram ID    → число от @userinfobot
    4) Ник для покупки     → Enter (будет @skimsuka)

  Когда появится «Запускаю бота…» — бот работает.
  Открой его в Telegram и нажми «Старт» (проверка — см. ИНСТРУКЦИЯ.txt, часть 4).

  Остановить бота:  Ctrl + C
  Запустить снова:  cd ~/phonebot && ./start.sh


──────────────────────────────────────────────────────────────
 ШАГ 5. Чтобы бот работал без открытого Терминала
──────────────────────────────────────────────────────────────

  Пока открыт Терминал со start.sh — бот работает. Закрыл — перестал.
  Чтобы бот работал в фоне и сам запускался после перезагрузки Mac:

  1. Останови бота в Терминале: Ctrl + C
  2. Включи автозапуск:

       cd ~/phonebot
       ./mac_autostart.sh

     Будет «✅ Бот работает в фоне…». Терминал теперь можно закрыть.

  3. Чтобы Mac не засыпал (иначе бот замолчит):
       Системные настройки → Аккумулятор (или Экран блокировки / Энергосбережение)
       → включи «Предотвращать автоматический переход в сон, когда дисплей выключен».
     У MacBook с закрытой крышкой без зарядки и внешнего монитора бот работать не будет.

  Управление фоновым ботом:

       cd ~/phonebot
       tail -f bot.log                 # смотреть, что делает бот (выход: Ctrl+C)
       ./mac_autostart.sh restart      # перезапустить после изменений
       ./mac_autostart.sh off          # выключить фоновый бот

  ⚠️ Не запускай одновременно ./start.sh и фоновый бот — будет ошибка
     «Conflict». Сначала ./mac_autostart.sh off, потом ./start.sh.


──────────────────────────────────────────────────────────────
 ШАГ 6. Изменить настройки
──────────────────────────────────────────────────────────────

  Открыть настройки в редакторе TextEdit:

    cd ~/phonebot
    open -e .env

  Или прямо в Терминале:

    nano .env
    # стрелками к нужной строке, исправь, затем Ctrl+O, Enter (сохранить), Ctrl+X (выйти)

  Что внутри:
    BOT_TOKEN=...        токен бота
    ADMIN_PASSWORD=...   пароль админки
    ADMIN_IDS=...        твой Telegram ID
    OWNER_CONTACT=...    ник для покупки (@skimsuka)

  Начать настройку заново (мастер снова задаст вопросы):

    cd ~/phonebot
    rm .env
    ./start.sh

  После изменений перезапусти бота:
    • если работает через start.sh — Ctrl+C и ./start.sh
    • если в фоне — ./mac_autostart.sh restart


──────────────────────────────────────────────────────────────
 ШАГ 7. Изменить модели и характеристики
──────────────────────────────────────────────────────────────

    cd ~/phonebot
    open -e products.py

  Каждая модель — одна строка. Исправь цифры или скопируй строку,
  чтобы добавить новую модель. Сохрани (Cmd+S) и перезапусти бота.

  ⚠️ Если открываешь в TextEdit: Формат → «Сделать простым текстом»,
     и выключи «умные кавычки» (Правка → Замены), иначе кавычки
     испортятся и бот не запустится. Надёжнее — бесплатный редактор
     VS Code (code.visualstudio.com).


──────────────────────────────────────────────────────────────
 Ручная установка (если start.sh не подходит)
──────────────────────────────────────────────────────────────

    cd ~/phonebot
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    python setup_env.py
    python bot.py

  В следующие разы:
    cd ~/phonebot && source .venv/bin/activate && python bot.py


──────────────────────────────────────────────────────────────
 Частые ошибки на Mac
──────────────────────────────────────────────────────────────

 zsh: permission denied: ./start.sh
   → chmod +x start.sh mac_autostart.sh

 «Нужен Python 3.10 или новее»
   → Установи Python с python.org (Шаг 2), закрой и открой Терминал.

 mv: rename phonebot ... No such file or directory
   → Архив скачался в другое место. Перетащи папку phonebot прямо
     в окно Терминала после слов  mv  (с пробелом), допиши  ~/phonebot

 «Telegram не принял токен»
   → cd ~/phonebot && rm .env && ./start.sh  — и вставь токен заново.

 «Нет связи с Telegram»
   → Проверь интернет. В России может понадобиться VPN.

 Бот в фоне не отвечает
   → cd ~/phonebot && tail -n 30 bot.log  — там будет причина.
     Проверь, что Mac не спит.

 Полностью удалить бота
   → cd ~/phonebot && ./mac_autostart.sh off
     cd ~ && rm -rf ~/phonebot
