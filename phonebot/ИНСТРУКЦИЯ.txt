   PHONEBOT — бот для сравнения техники Apple, Samsung, Xiaomi
   Подробная инструкция по установке и настройке
══════════════════════════════════════════════════════════════

Что умеет бот
  • Сравнивает 184 устройства: iPhone, iPad, Mac, Apple Watch, AirPods,
    Samsung Galaxy (S, Z Fold/Flip, A, Tab, Watch, Buds),
    Xiaomi, Redmi, POCO, Xiaomi Pad.
  • Сравнение кнопками или текстом: «iPhone 16 Pro vs Galaxy S25 Ultra».
  • Работает по подписке: без кода доступ закрыт.
  • Коды на 7 / 30 / 90 дней или навсегда ты создаёшь сам в админ-панели.
  • Бесплатный: никаких платных AI и сервисов.

Что понадобится
  • Компьютер на Windows или Mac (или сервер, см. ЧАСТЬ 5).
  • Telegram.
  • 15–20 минут.


──────────────────────────────────────────────────────────────
 ЧАСТЬ 1. Создаём бота в Telegram (5 минут)
──────────────────────────────────────────────────────────────

 1. Открой Telegram и найди в поиске @BotFather
    (с синей галочкой). Нажми «Запустить» / «Start».

 2. Отправь ему команду:   /newbot

 3. Он спросит имя бота. Напиши любое, например:
       Сравнение телефонов

 4. Он спросит юзернейм (адрес бота). Он должен быть на английском
    и заканчиваться на bot, например:
       skimsuka_phone_bot
    Если занято — придумай другой.

 5. BotFather пришлёт сообщение с ТОКЕНОМ. Он выглядит так:
       7123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
    Скопируй его целиком. Он понадобится в Части 3.

    ⚠️ Токен — это ключ от бота. Никому его не показывай.
       Если токен утёк: @BotFather → /mybots → твой бот →
       API Token → Revoke current token (выдаст новый).

 6. (Необязательно, но красиво) Там же в @BotFather:
       /setdescription — текст, который видят до нажатия «Старт»
       /setuserpic     — аватарка бота


──────────────────────────────────────────────────────────────
 ЧАСТЬ 2. Узнаём свой Telegram ID (1 минута)
──────────────────────────────────────────────────────────────

 1. Найди в Telegram бота @userinfobot и нажми «Старт».
 2. Он пришлёт сообщение, где будет строка Id: 123456789
 3. Запомни это число — это твой ID.

 Зачем: в админ-панель сможет войти только аккаунт с этим ID,
 даже если кто-то узнает пароль.


──────────────────────────────────────────────────────────────
 ЧАСТЬ 3. Запуск на компьютере
──────────────────────────────────────────────────────────────

 Шаг 3.1. Установи Python (один раз)

   WINDOWS:
     1. Открой https://www.python.org/downloads/
     2. Нажми жёлтую кнопку «Download Python 3.x».
     3. Запусти скачанный файл.
     4. ⚠️ ВНИЗУ ПЕРВОГО ОКНА ПОСТАВЬ ГАЛОЧКУ
        «Add python.exe to PATH» — это самое важное!
     5. Нажми «Install Now» и дождись конца.

   MAC:
     1. Открой https://www.python.org/downloads/
     2. Скачай и установи как обычную программу.

 Шаг 3.2. Распакуй бота

     Распакуй архив phonebot.zip в удобное место,
     например на Рабочий стол. Получится папка phonebot.

 Шаг 3.3. Запусти

   WINDOWS:
     Открой папку phonebot и дважды щёлкни по файлу  start.bat
     (если Windows пишет «Система Windows защитила компьютер» —
      нажми «Подробнее» → «Выполнить в любом случае»).

   MAC:
     1. Открой программу «Терминал».
     2. Напиши  cd  и пробел, перетащи папку phonebot в окно
        Терминала и нажми Enter.
     3. Напиши  ./start.sh  и нажми Enter.

 Шаг 3.4. Ответь на вопросы мастера настройки

     При первом запуске бот сам установит всё нужное (1–2 минуты)
     и задаст 4 вопроса:

       1) Токен бота          → вставь токен из Части 1
                                (в окне Windows вставка — правой кнопкой мыши)
       2) Пароль админ-панели → придумай свой или нажми Enter,
                                бот сгенерирует надёжный. ЗАПИШИ ЕГО.
       3) Твой Telegram ID    → число из Части 2
       4) Ник для покупки     → нажми Enter, будет @skimsuka

     Когда увидишь «Запускаю бота…» — бот работает! 🎉

     ⚠️ Бот работает, пока открыто это чёрное окно и включён
        компьютер. Закрыл окно — бот перестал отвечать.
        Чтобы бот работал всегда — смотри ЧАСТЬ 5.

     В следующие разы просто снова запускай start.bat (start.sh) —
     вопросов уже не будет.


──────────────────────────────────────────────────────────────
 ЧАСТЬ 4. Проверяем, что всё работает
──────────────────────────────────────────────────────────────

 1. Открой своего бота в Telegram (по юзернейму из Части 1)
    и нажми «Старт».
    → Будет «⛔ Подписка не активна» и кнопка «Купить код у @skimsuka».
      Так видят бота все новые пользователи.

 2. Нажми внизу «🛠 Админ-панель» и введи свой пароль.
    → «✅ Вход выполнен». Для тебя бот бесплатный и без ограничений.

 3. Нажми «⚖️ Сравнить технику» → «📱 iPhone» → выбери модель →
    «📱 Samsung Galaxy» → выбери модель.
    → Появится сравнение.

 4. Или просто напиши текстом:   iPhone 16 Pro vs Galaxy S25 Ultra

 5. Проверь продажу кода (лучше со второго аккаунта или попроси друга):
      • В админ-панели: «➕ Создать код» → «30 дней».
      • Бот пришлёт код вида ABCD-EFGH-JKLM — нажми на него, он скопируется.
      • Со второго аккаунта: «🔑 Ввести код» → вставить код.
      → «✅ Подписка активна до …» — бот у него заработал.


──────────────────────────────────────────────────────────────
 ЧАСТЬ 5. Чтобы бот работал круглосуточно (сервер)
──────────────────────────────────────────────────────────────

 Вариант А — бесплатно: оставлять компьютер включённым с открытым
 окном бота. Подходит, чтобы начать.

 Вариант Б — сервер (VPS). Это компьютер в интернете, который
 никогда не выключается. Самый дешёвый на Ubuntu стоит около
 200–400 ₽ в месяц (Timeweb Cloud, Aeza, Beget, Hetzner и др.).
 Бесплатный вариант — Oracle Cloud Free Tier, но регистрация сложнее
 (нужна карта для проверки).

 Пошагово:

 1. Купи VPS: система Ubuntu 22.04 или 24.04, самый дешёвый тариф.
    Тебе пришлют IP-адрес (например 185.10.20.30) и пароль root.

 2. Загрузи папку phonebot на сервер:
      WINDOWS: установи программу WinSCP (winscp.net).
               Протокол SFTP, хост — IP сервера, пользователь root,
               пароль из письма. Перетащи папку phonebot в /root/
      MAC:     программа Cyberduck (cyberduck.io), так же по SFTP.
    Папку .venv (если появилась после запуска на компьютере)
    загружать НЕ нужно. Файл .env можно загрузить — тогда мастер
    не будет задавать вопросы.

 3. Подключись к серверу:
      Открой «Командную строку» (Windows) или «Терминал» (Mac)
      и напиши:   ssh root@185.10.20.30   (свой IP)
      На вопрос «Are you sure…» напиши yes, затем введи пароль
      (символы при вводе не видны — это нормально).

 4. Выполни две команды:
      cd /root/phonebot
      bash server_install.sh

    Скрипт всё установит, задаст вопросы мастера (если нет .env)
    и включит автозапуск. В конце будет «✅ Готово».

 5. ⚠️ Останови бота на своём компьютере (закрой окно), иначе два
    бота будут мешать друг другу.

 Полезные команды на сервере:
      journalctl -u phonebot -f      — смотреть, что делает бот (выход Ctrl+C)
      systemctl restart phonebot     — перезапустить (после изменений)
      systemctl stop phonebot        — остановить
      systemctl status phonebot      — работает ли бот

 Если сервер в России и бот пишет «Нет связи с Telegram» —
 возьми сервер в другой стране (Нидерланды, Германия, Финляндия).


──────────────────────────────────────────────────────────────
 ЧАСТЬ 6. Как продавать подписку
──────────────────────────────────────────────────────────────

 1. Клиент открывает бота и видит «⛔ Подписка не активна».
 2. Он жмёт «💳 Купить код» — тебе в бот приходит уведомление:
       «💳 Хочет купить код: @ник_клиента»
    Кнопка «Купить код у @skimsuka» открывает ваш личный чат.
 3. Договариваетесь в личке, клиент оплачивает.
 4. Ты: «🛠 Админ-панель» → «➕ Создать код» → выбираешь срок.
 5. Нажимаешь на код (он скопируется) и пересылаешь клиенту.
 6. Клиент: «🔑 Ввести код» → вставляет → «✅ Подписка активна».
    Тебе приходит уведомление «✅ Код активирован».

 Что ещё есть в админ-панели:
   📋 Коды            — какие свободны, кто какой активировал
   👥 Подписчики      — у кого активна подписка и до какого числа
   🚫 Отключить       — отключить подписку по ID (ID есть в «Подписчики»)
   📊 Статистика      — сколько пользователей, подписок, сравнений
   🚪 Выйти           — выйти из админки

 Важно знать:
   • Каждый код одноразовый.
   • Новый код при действующей подписке продлевает её.
   • Пока подписка активна, бот работает без ограничений.


──────────────────────────────────────────────────────────────
 ЧАСТЬ 7. Как менять настройки и модели
──────────────────────────────────────────────────────────────

 Настройки — файл .env в папке бота (открывается Блокнотом).
 На Windows файл может быть не виден: в Проводнике включи
 «Вид» → «Показать» → «Скрытые элементы».

   BOT_TOKEN=...        токен бота
   ADMIN_PASSWORD=...   пароль админ-панели
   ADMIN_IDS=...        твой Telegram ID (несколько — через запятую)
   OWNER_CONTACT=...    ник для покупки (@skimsuka)
   DB_PATH=phonebot.db  файл с подписками и кодами

 После изменения .env перезапусти бота (закрой окно и запусти
 start.bat снова; на сервере — systemctl restart phonebot).

 Модели и характеристики — файл products.py (открой Блокнотом
 или любым редактором кода, например бесплатным VS Code).
 Каждая модель — одна строка. Чтобы исправить цифру — поправь её
 в строке. Чтобы добавить модель — скопируй соседнюю строку
 и поменяй значения. Сохрани файл и перезапусти бота.

 ⚠️ Характеристики заполнены по официальным данным производителей,
    но перед продажей подписки проверь их — особенно модели 2025 года,
    Redmi и POCO.

 Резервная копия: файл phonebot.db хранит все коды и подписки.
 Периодически копируй его в надёжное место.


──────────────────────────────────────────────────────────────
 ЧАСТЬ 8. Если что-то не работает
──────────────────────────────────────────────────────────────

 «Python не найден» / «python не является командой»
   → Переустанови Python и поставь галочку «Add python.exe to PATH».
     После установки закрой и снова открой окно.

 Окно start.bat сразу закрывается
   → Запусти через командную строку, чтобы увидеть ошибку:
     в адресной строке папки напиши cmd, Enter, затем start.bat

 «Telegram не принял токен»
   → Токен скопирован с ошибкой. Удали файл .env и запусти бота
     снова — мастер спросит токен заново.

 «Нет связи с Telegram»
   → Проверь интернет. В России Telegram может работать с перебоями:
     включи VPN на компьютере или используй сервер за границей.

 «Conflict: terminated by other getUpdates request»
   → Бот запущен в двух местах одновременно. Оставь один.

 Бот не отвечает в Telegram
   → Проверь, что окно бота открыто (или на сервере:
     systemctl status phonebot должно быть active (running)).

 Не пускает в админ-панель
   → Проверь пароль и ADMIN_IDS в .env (там должен быть ТВОЙ ID).
     После 5 неверных паролей вход блокируется на 15 минут.

 Бот «не знает» модель
   → Её нет в базе. Добавь строку в products.py (см. Часть 7).

 Безопасность
   • Файл .env никому не отправляй — там токен и пароль.
   • Не выкладывай .env и phonebot.db в открытый доступ.
   • Сообщение с паролем админки бот сразу удаляет из чата.
